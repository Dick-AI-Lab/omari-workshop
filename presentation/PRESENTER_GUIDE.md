## Discussion prompts at a glance

- **Slide 1, Title:** Who here has reviewed fetal ultrasound images? Who has trained an image model?

```text
SLIDE 3 · Three models, one image
Time: 3 min  (chapter window 0–10 min)

MAIN MESSAGE
We compare three ways of learning image representations, chosen to differ in architecture and in what they learned before seeing our labels.

TALKING POINTS
```

### Slide 5: Why ultrasound is hard for humans and machines

```text
SLIDE 5 · Why ultrasound is hard for humans and machines
Time: 3 min  (chapter window 10–25 min)

MAIN MESSAGE
Ultrasound images are noisy, operator-dependent and scanner-dependent; a model has to cope with all of that.

TALKING POINTS
• Speckle: the grainy texture is an interference pattern, not tissue structure.
```

### Slide 6: FETAL_PLANES_DB at a glance

```text
SLIDE 6 · FETAL_PLANES_DB at a glance
Time: 4 min  (chapter window 10–25 min)

MAIN MESSAGE
12,400 images from 1,792 patients in six classes, with strong class imbalance.

TALKING POINTS
• Classes range from 711 abdomen images to 4,213 'Other' images.
• Imbalance affects both training (we used a class-weighted loss) and evaluation (we report macro-F1, which weights each class equally).

• Test set: 5,271 images from 896 patients, nearly as large as the training set (6,425 images).

FOR A MIXED AUDIENCE
If one class dominates, a model can score well by favouring it. That is why we look beyond accuracy.

WEBSITE

ASK THE ROOM
```

### Slide 7: Split by patient, not by image

```text
SLIDE 7 · Split by patient, not by image
Time: 4 min  (chapter window 10–25 min)

MAIN MESSAGE
Images from the same patient look alike, so every patient must sit entirely in train, validation or test. Otherwise test scores are inflated.

TALKING POINTS
• Our split is patient-disjoint: 809 / 87 / 896 patients, overlap 0.
• Patient-disjoint is not the same as dissimilar: a deliberately loose perceptual-hash detector flags 2,685 look-alike pairs between training/validation and test images (from different patients), involving 320 test images.
• Scanner shift is built into the official split: Voluson S10 contributes 11 training images but 1,071 test images.
• Model selection used only the validation patients; the test set was used once for reporting.

FOR A MIXED AUDIENCE
If you study with this year's exam questions, your grade says little about what you learned. Image-level splitting does exactly that with patients.

WEBSITE
Chapter 2 split audit and leakage simulator show these numbers and what leakage does to a score.

ASK THE ROOM
• Where else could leakage hide in a clinical dataset (same visit, same machine, same operator)?

SCIENTIFIC CAVEATS
• dHash flags perceptually generic frames, not only copies; it is a screening signal, not proof of duplication.
• The diagram is illustrative; the numbers are from the project's split manifest.
```

### Slide 9: DenseNet-161: local filters, reused features

```text
SLIDE 9 · DenseNet-161: local filters, reused features
Time: 5 min  (chapter window 25–50 min)

MAIN MESSAGE
A CNN slides small learned filters across the image; stacking them builds features from edges to anatomy. DenseNet feeds every layer the outputs of all earlier layers in its block.

TALKING POINTS
• Convolution: the same small weight pattern is applied everywhere. That is locality and weight sharing.
• Hierarchy: deeper layers see larger regions (receptive field grows) at lower resolution.
• Dense connectivity: each layer receives the concatenation of all previous feature maps, so features are reused rather than relearned.
• Classification: global average pooling turns the final 7×7 maps into one vector, followed by a linear layer to six classes. This pooling is what makes CAM possible in Chapter 5.

FOR A MIXED AUDIENCE
Imagine a set of stencils for small patterns; the network learns which stencils matter and combines them layer by layer.

WEBSITE
Chapter 3A: kernel explorer, receptive-field table and dense-block connectivity diagram.

ASK THE ROOM
• Why might weight sharing suit ultrasound, where the same texture appears everywhere?

SCIENTIFIC CAVEATS
• Diagram is schematic; DenseNet-161 has four dense blocks with 6, 12, 36 and 24 layers.
```

### Slide 11: ViT-B/16: an image as a sequence of patches

```text
SLIDE 11 · ViT-B/16: an image as a sequence of patches
Time: 4 min  (chapter window 25–50 min)

MAIN MESSAGE
A Vision Transformer cuts the image into 16×16-pixel patches, turns each into a vector (a token), adds position information, and lets all tokens interact.

TALKING POINTS
• 224×224 input → 14×14 = 196 patches of 16×16 pixels.
• Each patch is flattened and linearly projected to a 768-dimensional token; a learned position embedding records where it came from.
• A special [CLS] token is added; after 12 transformer blocks its final state feeds the classifier.
• There is no built-in notion of locality: neighbouring patches must learn to relate to each other.

FOR A MIXED AUDIENCE
Like cutting a picture into a jigsaw, writing a description of each piece, and numbering the pieces so their arrangement isn't lost.

WEBSITE
Chapter 3B: patch → token explorer, including the similarity of the learned position embeddings.

ASK THE ROOM
• What might be lost when an image is cut into fixed 16-pixel squares?

SCIENTIFIC CAVEATS
• Diagram uses the real opening image resized to the 224×224 model input; the token strip is schematic.
```

### Slide 12: Self-attention: every patch can consult every other

```text
SLIDE 12 · Self-attention: every patch can consult every other
Time: 5 min  (chapter window 25–50 min)

MAIN MESSAGE
Self-attention lets each token gather information from all others, weighted by learned similarity. The weights are inspectable, but they are not an explanation.

TALKING POINTS
• Each token emits a query, a key and a value; attention weights are the softmax of query–key similarity; the output is the weighted sum of values.
• 12 heads per block learn different relations; there are 12 blocks.
• Panels: real [CLS]-token attention of the trained ViT-B/16 on the opening image, averaged over the 12 heads, after blocks 1, 6 and 12.
• Early attention is broad; later it concentrates on a few tokens, including a patch in the black corner (an 'attention sink' that carries little anatomy).

FOR A MIXED AUDIENCE
Attention is where the model routes information, a bit like who talks to whom in a meeting. It does not tell you which remark decided the vote.

WEBSITE
Chapter 3B attention explorer: choose block, head and query patch; compare ViT-B/16 with USF-MAE.

PRESENTER CUE
Ask participants to open Chapter 3, select an ultrasound image, and compare attention patterns across transformer blocks.

ASK THE ROOM
• Does a bright attention region necessarily mean it influenced the predicted class?

SCIENTIFIC CAVEATS
• Attention weights are not faithful attributions by default (Jain & Wallace 2019); Chapter 5 tests this.
• Head-averaging hides head-specific patterns; maps are min–max scaled per panel.
```

### Slide 13: USF-MAE: learning from unlabelled ultrasound

```text
SLIDE 13 · USF-MAE: learning from unlabelled ultrasound
Time: 3 min  (chapter window 25–50 min)

MAIN MESSAGE
A masked autoencoder hides most patches and learns to reconstruct them. To do that well on ultrasound, the encoder must learn ultrasound structure, without any labels.

TALKING POINTS
• During pretraining the encoder sees only the visible patches; a small decoder predicts the pixels of the masked ones; the loss is computed on masked patches only.
• USF-MAE was pretrained this way on ~370k unlabelled ultrasound images (OpenUS-46), starting from ImageNet MAE weights. Our classifier uses the 500-epoch checkpoint.
• Panels: real reconstructions by the 500-epoch USF-MAE checkpoint of the opening image at 25, 50, 75 and 90% masking (visible patches pasted back).
• Masked-patch reconstruction error (MSE in the model's normalised input space) grows with the masking ratio: 25%: 0.116, 50%: 0.162, 75%: 0.247, 90%: 0.497.

FOR A MIXED AUDIENCE
Like a fill-in-the-blanks exercise for images: guessing the missing pieces forces the model to learn what ultrasound anatomy usually looks like.

WEBSITE
Chapter 3C: masking explorer (ratio, seed) and the authentic 500-epoch reconstructions; the historical 100-epoch images are behind a clearly labelled toggle.

ASK THE ROOM
• At 90% masking the reconstruction is blurry but plausible. What has the model learned, and what has it not?

SCIENTIFIC CAVEATS
• Reconstructions show what the pretrained encoder–decoder can infer, not what the fine-tuned classifier uses.
• All images on this slide are from usf_mae_500ep.pth (sha256 c659a061…); the 100-epoch checkpoint is not used anywhere in this deck.
```

### Slide 14: From reconstruction to classification

```text
SLIDE 14 · From reconstruction to classification
Time: 2 min  (chapter window 25–50 min)

MAIN MESSAGE
After pretraining, the decoder is discarded; the encoder plus a new six-way head is fine-tuned with labels, exactly as for the other two models.

TALKING POINTS
• Pipeline: ImageNet MAE → USF-MAE pretraining on unlabelled ultrasound (500 epochs) → fine-tune encoder + linear head on labelled FETAL_PLANES_DB training patients.
• Pretraining overlap: USF-MAE's unlabelled pretraining corpus (OpenUS-46) included FETAL_PLANES_DB images, possibly including our test images.
• This is not label leakage (no labels were used in pretraining), but it is transductive exposure: the encoder may have seen the test images' pixels. It could favour USF-MAE, especially with few labels and on the Voluson S10 scanner.
• The overlap is stated by the project configuration and has not been independently verified.

FOR A MIXED AUDIENCE
It is a bit like having flipped through the exam booklet without the answer key: you never saw the answers, but the pictures are familiar.

WEBSITE
Chapter 3C overlap callout; the same disclosure travels with every USF-MAE result on the site.

ASK THE ROOM
• How would you design an experiment that removes this overlap?

SCIENTIFIC CAVEATS
• Do not describe the overlap as 'leakage' without qualification; it is unlabelled exposure.
• An external test set or a pretraining corpus with FETAL_PLANES_DB removed would be needed to settle its effect.
```

### Slide 17: Fine-tune, select, then test once

```text
SLIDE 17 · Fine-tune, select, then test once
Time: 3 min  (chapter window 50–70 min)

MAIN MESSAGE
All three encoders get a new six-way head and are fine-tuned; the validation patients choose the checkpoint; the test patients are used once.

TALKING POINTS
• Training: class-weighted loss, augmentation (small rotations, scaling, flips, brightness/contrast), up to 25 epochs with early stopping on validation macro-F1.
• Accuracy counts correct images; it is dominated by large classes such as 'Other'.
• Macro-F1 averages the per-class F1 scores, so the smallest class counts as much as the largest.
• We also report 95% confidence intervals from a patient-clustered bootstrap (1,000 resamples).

FOR A MIXED AUDIENCE
Accuracy asks 'how often right overall?' Macro-F1 asks 'how good on each type of image, on average?'

WEBSITE
```

### Slide 26: From CAM to Grad-CAM++

```text
SLIDE 26 · From CAM to Grad-CAM++
Time: 5 min  (chapter window 80–105 min)

MAIN MESSAGE
Class activation maps weight the final convolutional feature maps by how much each one supports the class, then sum them into a heatmap.

TALKING POINTS
• CAM: uses the classifier weights directly; needs global average pooling right before the classifier (DenseNet has it).
• Grad-CAM: weights each feature map by the average gradient of the class score; works at any convolutional layer.
• Grad-CAM++: uses higher-order gradient terms to weight pixels, which can help when several regions support the class.
• Resolution matters: DenseNet's final features are 7×7, so each cell covers a 32×32-pixel region of the 224×224 input. Heatmaps are upsampled and look smoother than they are.

FOR A MIXED AUDIENCE
Ask the network: which of your detectors fired for 'abdomen', and where were they firing? Blend those detector maps, weighted by importance.

WEBSITE
Chapter 5 toy CAM / Grad-CAM / Grad-CAM++ panel with a deletion curve; the real lab follows.

ASK THE ROOM
• Why might a 7×7 map miss a thin structure like a femur?

SCIENTIFIC CAVEATS
• Formula shown is Grad-CAM; Grad-CAM++ changes how α is computed.
• All maps are post-hoc and depend on the chosen layer.
```

### Slide 27: Attribution for transformers

```text
SLIDE 27 · Attribution for transformers
Time: 4 min  (chapter window 80–105 min)

MAIN MESSAGE
Transformers have no convolutional feature maps, so we use the tokens and the attention matrices. Different methods answer different questions.

TALKING POINTS
• Attention rollout (Abnar & Zuidema 2020): multiply the attention matrices of all 12 blocks to trace how information flows to [CLS]. It is class-agnostic.
• Gradient-weighted attention rollout: weights each block's attention by its gradient for the target class before rolling out. This is the workshop's simplified, Chefer-inspired variant (no LRP); older files call it 'chefer'.
• Token Grad-CAM / Grad-CAM++: Grad-CAM applied to the 14×14 patch tokens after a chosen block.
• Panels: USF-MAE on the opening image. Plain rollout lands on the image edge and the black corner; adding class gradients moves it onto the abdomen.
```
